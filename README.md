# Road Accidents Analysis

Machine learning project on road accident data (2019-2023) with weather conditions.

## Dataset
- File: `morth_road_accidents_weather.csv`
- Replicated/sample dataset modelled on MoRTH road accident data
- Covers 2019 to 2023

## Notebook
- `Road Accidents.ipynb`: EDA (weather and year-wise charts) and modeling

## Techniques
- Class imbalance handling: class weights, SMOTE
- Evaluation: F1 score (not accuracy alone)

## Run in Colab
Open the notebook from GitHub: File → Open notebook → GitHub tab.
